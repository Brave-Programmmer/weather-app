# Weather App

A simple weather application built with **React** that fetches weather information using the **OpenWeather API**.

## Features

* Search weather by city
* Display temperature and weather conditions
* Uses OpenWeather API for weather data
* Built with React

## Tech Stack

* React
* JavaScript
* CSS
* OpenWeather API

> **Note:** This project is currently deprecated because the API/version it was built with is no longer maintained. OpenWeather currently provides newer weather API products and endpoints.
